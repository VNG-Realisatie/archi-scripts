Hier vind je de Archi scripts die worden gebruikt bij het maken en onderhouden van de [GEMMA ArchiMate-modellen](https://github.com/VNG-Realisatie/GEMMA-Archi-repository) en de VNGR projectarchitecturen, zoals de projectarchitectuur [Omgevingswet](https://github.com/VNG-Realisatie/Omgevingswet-Archi-repository).

Zie de pagina [Archi scripting](https://redactie.gemmaonline.nl/index.php/Archi_scripting) voor een handleiding voor het installeren van de jArchi plugin.

De scripts maken gebruik van CommonJS. 
> Krijg je de fout "**ReferenceError: "require" is not defined**", wijzig dan de Archi Scripting configuratie:
> *Edit > Preferences > Scripting* — selecteer als JavaScript-engine *GraalVM* en schakel *CommonJS* in.

Hoe de scripts gebruikt moeten worden, is (meestal) bovenin het script beschreven. Hieronder vind je welke scripts er zijn en wat deze doen. De tabel is niet uitputtend; het zijn de meest gebruikte scripts.

| Folder           | Scripts         |
| ---------------- | ------------- |
| /root folder      | Veelgebruikte scripts in root voor snelle toegang.<ul><li>**addProperty**: voeg property met waarde toe aan geselecteerde concepten</li><li>**copyFormat**: kopieer opmaak naar alle objecten in view</li><li>**mergeElement**: voeg gelijknamige elementen van hetzelfde type samen; behoud relaties, view-occurrences en properties</li><li>**mergeRelation**: voeg gelijknamige relaties samen</li><li>**removeBendpoints**: verwijder bendpoints in geselecteerde view of relaties</li><li>**reverseRelation**: keer richting van geselecteerde relaties om</li></ul>                                                                                                                                |
| _lib             | Generieke hulpfuncties voor andere scripts. Bevat Node.js-libraries en:<ul><li>**common.js**: logging en debugging</li><li>**selection.js**: selecteren van objecten in model tree of view</li></ul>Modules hebben extensie `.js` (niet zichtbaar in Archi). Uitvoerbare Archi-scripts hebben extensie `.ajs`.                                                                                                                                                                                                                                                         |
| Appearance       | Opmaken van views (selecteer view of objecten in view).<ul><li>**colorByProperty**: kleur op basis van propertywaarde</li><li>**setDefaultFormat**: reset naar Archi-standaardopmaak</li><li>**toggleFigure**: wissel figure-weergave</li></ul>                                                                                                                                                                                      |
| Beheren          | Bulk beheren en opschonen van objecten.<ul><li>**createProjectmodel**: kopieer referentiemodel en behoud alleen projectrelevante objecten</li><li>**deleteEmptyFolders**: verwijder lege folders in geselecteerd model of folder</li><li>**deleteUnusedElements**: verwijder concepten die niet in views voorkomen</li><li>**findDuplicateRelations**: toon id’s van dubbele relaties in console</li><li>**find_Id_or_Name_InModels**: zoek op object-ID of naam in geopende modellen</li></ul>                                                                                                                                                                                                          |
| Convert to       | Wijzig ArchiMate-type van een concept. Vanaf Archi 5.1 standaard beschikbaar (rechtsklik > set concept type). Extra: uitgebreide logging en herstel van ongeldige relatietypen waar mogelijk.                                                                                                                                                                                                                                        |
| Develop          | Hulpmiddelen voor scriptontwikkeling.<ul><li>**plotColorCode**: toon kleurcodes in view</li><li>**plotID**: toon Archi-id’s in view</li></ul>                                                                                                                                                      |
| GEMMA            | Specifiek voor beheer van het GEMMA-model.<ul><li>**createReleaseModel**: maak tijdelijk gefilterd model voor AMEFF-export:<ul><li>filter: verwijder views zonder `publiceren=GEMMA online`, ongebruikte elementen en lege folders</li><li>set modelproperty `release=<today>`</li><li>voer **setObjectID** uit</li></ul></li><li>**GGM folder**: import/export van GGM-CSV-bestanden</li><li>**plotBetrouwbaarheidSom**: toon BIV-waarden en kleur op som</li><li>**plotObjectID**: toon Object ID’s in view</li><li>**setObjectID**: controleer en maak unieke Object ID’s voor elementen, relaties en views</li><li>**used_once folder**: eenmalige bulkbewerkingen, zoals **change_AF2AS**</li></ul> |
| ImportExport_CSV | Export en import van elementen, relaties en views met properties.<ul><li>**export_element**: exporteer elementen naar CSV</li><li>**export_relation**: exporteer relaties naar CSV</li><li>**export_view**: exporteer views naar CSV</li><li>**import**: werk properties bij; waarde `<remove>` verwijdert property</li><li>**import_sync**: verwerk import en registreer datum in *created*, *updated*, *deleted*; verwijderde objecten krijgen prefix `[DELETED]`</li></ul>Import is ongedaan te maken met Ctrl-Z. Gebruik bij voorkeur LibreOffice Calc i.p.v. Excel (characterset).                                                                                                                  |
| Layout           | Layout van relaties in view.<ul><li>**Create <*>-shaped relations**: maak stervormige bendpoints</li><li>**removeBendpoints**: verwijder bendpoints</li><li>**Spread relations orthogonally**: verdeel overlappende relaties orthogonaal</li></ul>                                                                                                                                                                                   |
| Report           | Genereer rapport op basis van view (gebaseerd op script van Richard Heward – Tame Blue Lion Ltd).<ul><li>**exportImage**: genereer markdown met view en elementtabel</li><li>**generate_report**: genereer markdownrapport op basis van driving view</li></ul>                                                                                                                                                                       |
| Sync from CSV    | Importeer CSV en maak of actualiseer meerdere objecttypen en relaties.                                                                                                                                                                                                                             |
| View             | Genereer views met directed layout (configureerbaar; zie readme.md).<ul><li>**_expand**: voeg gerelateerde elementen toe aan geselecteerde elementen in view</li><li>**_generate**: genereer view van selectie; de view bevat de geselecteerde elementen en alle direct gerelateerde elementen.</li><li>**_generate_multiple**: genereer voor ieder geselecteerd element een view</li><li>**_layout_LR** en **_layout_TB**: pas layout Links-naar-Rechts of Top-naar-Bottom toe</li><li>**_layout_nested_LR** en **_layout_nested_TB**: layout met nesting (standaard aggregation-relaties)</li></ul>Nesting is beperkt ondersteund en kan fouten geven.                                                                                       |
